## 📦 Installation (Termux)

```bash
pkg install python git
pip install requests
git clone https://github.com/darkvibez456/proxyvault
cd proxyvault
python proxyvault.py
```

## 📦 Installation (Linux)

```bash
git clone https://github.com/darkvibez456/proxyvault
cd proxyvault
pip install -r requirements.txt
python3 proxyvault.py
```

## ⚡ Features

- 🌐 HTTP, HTTPS, SOCKS4, SOCKS5 scraping
- ✅ Live proxy checker with latency
- 🗺️ Country + flag detection
- 🧵 Multi-threaded fast checking
- 💾 Export to TXT
- 📋 Load from file
- 🎨 Clean color terminal UI
- 📱 Termux support

## 🚀 Usage

```
[1] Scrape & Show Proxies
[2] Scrape + Live Check
[3] Load from file & Check
[4] Export results
[0] Exit
```
